## Téléchargement
La dernière version est dans **[Releases](../../releases)** : téléchargez
`SRM Lab Setup.exe`, installez, c'est tout. **Les mises à jour sont ensuite
automatiques** au démarrage.

## Sécurité & respect d'iRacing
🔒 100 % local · SDK **officiel** (mémoire partagée) · **aucun** accès à la
mémoire du jeu · **aucune** interception réseau · **aucune** donnée personnelle
envoyée. Conforme aux conditions d'utilisation d'iRacing.

## Fonctionnalités
Overlay transparent éditable · widgets (Race HUD, Relative, Delta, Pneus,
Session, Incidents, Drapeaux, Carte circuit, Limiteur…) · dashboards GT
multi-pages · ingénieur de course vocal (annonces live FR/EN) · multi-écrans.

## Radar (en attente)
Le radar de proximité est **volontairement laissé désactivé** pour l'instant : à
cause de certains bugs et du fait qu'iRacing **ne partage pas toutes les
informations** nécessaires, je préfère ne pas le livrer tant que je n'ai pas
trouvé une meilleure solution. Un radar du même type que celui d'iRacing pourra
être ajouté si besoin, mais je préfère le laisser vide tant que je n'ai pas de
réponse solide, plutôt que de sortir quelque chose de bancal.

## 🇬🇧 English

**HUD overlay & race engineer for iRacing** — 100 % local, built on the
**official iRacing SDK**. Windows.

> 🌐 A full **English translation of the whole app** is coming soon. The interface
> is currently in French — an in-app English option is on the way.

### Download
Grab the latest build from **[Releases](../../releases)**: download
`SRM Lab Setup.exe`, install, done. **Updates are then automatic** at startup.

### Security & iRacing compliance
🔒 100 % local · **official** SDK (shared memory) · **no** game-memory access ·
**no** network interception · **no** personal data sent. Compliant with iRacing's
Terms of Service.

### Features
Editable transparent overlay · widgets (Race HUD, Relative, Delta, Tyres,
Session, Incidents, Flags, Track Map, Pit Limiter…) · multi-page GT dashboards ·
**voice race engineer — fully working, with live FR/EN announcements** ·
multi-monitor support.

### Radar (on hold)
The proximity radar is **intentionally left disabled** for now: because of some
bugs and the fact that iRacing **does not expose all the data** it needs, I'd
rather not ship it until I find a better solution. An iRacing-style radar can be
added if needed — but I prefer to leave it empty until I have a solid answer,
rather than release something unreliable.
