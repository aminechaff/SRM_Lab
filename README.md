## Téléchargement
La dernière version est dans **[Releases](../../releases)** : téléchargez
`SRM Lab Setup.exe`, installez, c'est tout. **Les mises à jour sont ensuite
automatiques** au démarrage.

## Sécurité & respect d'iRacing
🔒 100 % local · SDK **officiel** (mémoire partagée) · **aucun** accès à la
mémoire du jeu · **aucune** interception réseau · **aucune** donnée personnelle
envoyée. Conforme aux conditions d'utilisation d'iRacing.

## Fonctionnalités
Overlay transparent éditable · widgets (Race HUD, Relative, Delta, Pneus,
Session, Incidents, Drapeaux, Carte circuit, Limiteur…) · dashboards GT
multi-pages · ingénieur de course vocal (annonces live FR/EN) · multi-écrans.
